# Typography Standards

## Primary Typeface Pairings
- **Headings (H1, H2, H3):** Poppins (Bold / SemiBold) — geometric, approachable, modern clean look.
- **Body & Microcopy:** Inter (Regular / Medium) — high legibility, clean spacing.

## Hierarchy & Scale
- **H1 Hero Heading:** 40px / 48px line height (Mobile 30px / 38px)
- **H2 Section Heading:** 32px / 40px line height (Mobile 24px / 32px)
- **H3 Card Title:** 22px / 28px line height
- **Body Text:** 16px / 24px line height (`#222222`)
- **Badge & Meta Text:** 14px / 20px line height (`#5B5B5B`)
