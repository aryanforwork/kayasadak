# Responsive HTML Pricing Table Component Spec

## Component Architecture
- Renders as a semantic `<table>` element.
- Column Headers (Display Order): **Platinum** (`#D9D9E3`), **Gold** (`#A87C2E`), **Silver** (`#B8BCC2`).
- Row Headers: 3 days/week (12 sessions), 4 days/week (16 sessions), 5 days/week (20 sessions).
