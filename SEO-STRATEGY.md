## 3. Locality Content Strategy — Superseded Section (Read This Before Building Any Locality Page)

v1 of this document (and the earlier standing competitor research) assumed
matching the reference competitor's ultra-granular, sector-by-sector page
structure (e.g., a dedicated page for Dwarka Sector 12 specifically). The
client has since supplied a purpose-built local SEO reference document
that explicitly recommends clustering instead, to avoid thin content and
keyword cannibalization. **This clustering approach is now the locked
strategy** — see SITEMAP-AND-IA.md §2a for the exact resulting page list.

Practical implication for Sub-Agent 4 and Sub-Agent 6: each cluster page
(e.g., "West Delhi" covering Rajouri Garden, Janakpuri, Dwarka, Paschim
Vihar, Punjabi Bagh) must be written to rank for searches on EACH named
sub-locality within it — through natural mentions, real local texture, and
FAQ entries per sub-area — not just the cluster name itself. This achieves
similar long-tail coverage to the competitor's micro-page approach without
the thin-content/cannibalization risk the client's reference file warns
against.
