# Teacher Tier Badge System Spec (Option A Aligned)

## Display Order & Price Alignment
Display listing order across all components (pricing tables, directory filters, teacher cards) is:
**Platinum → Gold → Silver**

Under **Option A**, display order matches price and qualification hierarchy:

1. **Platinum (Top Tier):**
   - **Rate:** ₹1,000 / session
   - **Qualifications:** Complete Masters + Graduation + Advanced Teacher Training Course + 10+ years experience
   - **Badge Style:** Soft pearl/platinum pill (`#D9D9E3`)

2. **Gold (Mid Tier):**
   - **Rate:** ₹750 / session
   - **Qualifications:** Graduation in Yoga + Advanced Teacher Training Course + 7+ years experience
   - **Badge Style:** Deep warm gold pill (`#A87C2E`)

3. **Silver (Entry Tier):**
   - **Rate:** ₹500 / session
   - **Qualifications:** Graduation + Diploma in Yoga + 5+ years experience
   - **Badge Style:** Cool silver pill (`#B8BCC2`)

## Hover / Micro-copy Behavior
When a visitor hovers or taps on any tier badge, a tooltip/popover displays the one-line qualification summary (e.g. "Platinum — Masters + 10+ yrs experience").
